# Human Activity Recognition Using Machine Learning

## Project Overview
This project focuses on Human Activity Recognition (HAR) using smartphone sensor data from the UCI Human Activity Recognition dataset.

The objective is to classify human activities using machine learning algorithms and explore the effectiveness of different feature extraction techniques.

## Dataset
- UCI Human Activity Recognition Using Smartphones Dataset
- Sensor data collected using smartphone accelerometers and gyroscopes.

## Techniques Used
- Exploratory Data Analysis
- Principal Component Analysis (PCA)
- Feature Extraction
- Time-domain and Frequency-domain Analysis
- GroupKFold Cross-Validation
- Hyperparameter Tuning

## Machine Learning Algorithms
- Logistic Regression
- Random Forest Classifier

## Libraries Used
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
